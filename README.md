# Chaos Chess (카오스체스)

기물마다 능력이 다른 체스 응용 턴제 웨이브 게임이에요. 브라우저에서 바로 돌아가고 빌드 과정이 없어요.

## 실행

ES 모듈을 쓰기 때문에 파일을 더블클릭하지 말고 정적 서버로 열어주세요.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

## 배포

GitHub Pages(`gh-pages` 브랜치)로 배포해요. 배포 전에 `python3 tools/bump-version.py`를 실행하면 모든 스크립트·음원 주소에 새 버전이 붙어서, 브라우저가 예전 파일을 캐시에서 꺼내 쓰지 않아요.

## 게임 구조

- **메인 화면**: 상점, 편성, 출전. 골드와 보유 기물은 브라우저에 저장돼요(영구 성장).
- **상점**: 등급(기본·일반·희귀·영웅·전설)과 성능에 따라 가격이 달라요. 카드마다 이동(청록)·공격(빨강) 패턴 미니맵이 있어요.
- **편성**: 앞줄 8칸, 뒷줄 8칸. 킹은 꼭 넣어야 해요. 기물을 팔면 반값을 돌려받아요.
- **전투**: 내 기물을 고르고 표시된 칸을 누르면 선택지(이동, 공격, 능력)가 나와요. 한 턴에 기물 하나만 움직여요.
  - 근접 기물은 적을 쓰러뜨리면 그 칸으로 전진하고, 원거리 기물은 제자리에서 쏴요.
  - 적을 모두 쓰러뜨리면 다음 웨이브로 넘어가요. 웨이브가 오를수록 적의 수, 등급, 체력, 공격력이 올라가고 5의 배수 웨이브엔 마왕이 나와요.
  - 웨이브 사이엔 상점이 없어요. 쓰러진 기물은 그 출전에서 돌아오지 않아요. 살아남은 기물은 원래 자리로 돌아가고 최대 체력의 20%를 회복해요. 그다음 아래 두 줄 안에서 자리를 바꿀 수 있어요.
  - 킹이 쓰러지면 출전이 끝나요. 번 골드는 그대로 남아요.

## 화면 구성

- 메인: 메뉴, 내 편성과 첫 웨이브 미리보기, 내 군대 통계, 최근 출전, 오늘의 팁
- 상점, 편성(편성 요약 포함), 도감(적과 소환수는 만나야 공개), 기록(누적 통계와 출전 이력), 게임 방법
- 전투: 웨이브 진행 막대, 아군·적 현황 목록, 기물 정보, 전투 기록
- 모든 화면 뒤에 움직이는 픽셀 배경(밤하늘, 성, 떠다니는 체스 말 섬)이 깔리고, 화면마다 분위기가 달라요. 마왕 웨이브에선 하늘이 붉어져요.

## 레벨업 (영구 성장)

- 편성 화면에서 기물을 고르고 레벨업합니다. 최대 Lv3, 보유한 기물마다 따로 저장됩니다.
- 값: Lv2는 구매가의 약 1.2배, Lv3은 약 1.45배 (킹은 120 기준).
- 능력치: Lv2 체력 +25%, Lv3 체력 +50%와 공격력 +1.
- 특성: 기물마다 Lv2·Lv3에 서로 다른 특성이 붙습니다 (`LEVEL_TRAITS`). 결계, 처형, 가시, 재생, 질주, 사거리 증가, 숙련, 반격, 흡혈, 독, 빙결, 파편, 돌 피부, 지휘, 수호, 환생, 급습.
- 생김새: Lv2는 파란 허리띠와 받침대, Lv3은 금빛 허리띠·받침대와 머리 위 고리. 전투에서는 발밑 오라(파랑/금빛)와 공격 시 레벨 색 폭발.
- 스킬: 레벨이 오를 때마다 전투에서 직접 쓰는 스킬이 하나씩 열립니다 (`LEVEL_SKILLS`). 철벽, 돌격, 회오리 베기, 격려, 응급 처치, 밀쳐내기, 화살비, 저격, 냉기 폭발, 독 안개, 그림자 도약, 낙뢰, 땅울림, 참수, 축복. 스킬마다 재사용 대기 시간이 따로 있습니다.
- 깊은 웨이브에서는 적도 Lv2(6웨이브부터), Lv3(12웨이브부터)으로 나오고 스킬을 씁니다.

## 소리와 화면 전환

- 메인 화면, 전투, 마왕 웨이브마다 배경음악이 바뀌어요(크로스페이드). 웨이브 시작·클리어·게임 오버엔 징글이 나와요.
- 효과음은 기물 위치에 따라 좌우로 패닝되고, 같은 동작도 매번 음높이가 조금씩 달라요.
- 왼쪽 아래 버튼에서 배경음악·효과음 크기를 조절하거나 끌 수 있어요.
- 화면이 바뀔 땐 체스판 칸이 대각선으로 튀어나와 덮었다가 걷혀요. 출전할 땐 나이트가 L자로 뛰어 지나가고, 패배하면 진홍색 칸이 덮여요.

## 특수 능력 기물

| 기물 | 등급 | 능력 |
|---|---|---|
| 창병 | 일반 | 가로세로 두 칸을 꿰뚫어 찌르기 |
| 궁수 | 일반 | 2~4칸 원거리 사격 |
| 방패병 | 일반 | 옆 아군 받는 피해 -1 |
| 화염술사 | 희귀 | 화염구: 3×3 범위 피해 |
| 빙결술사 | 희귀 | 맞은 적은 다음 턴 행동 불가 |
| 사제 | 희귀 | 치유 |
| 암살자 | 희귀 | 체력이 가득 찬 적에게 두 배 피해 |
| 네크로맨서 | 영웅 | 보라색 해골 소환, 근처에서 쓰러진 적을 해골 아군으로 |
| 뇌전술사 | 영웅 | 연쇄 번개 |
| 광전사 | 영웅 | 처치할 때마다 공격력 +1 |
| 드래곤 | 전설 | 한 줄 3칸 화염 숨결 |
| 시간술사 | 전설 | 순간이동, 시간 가속(연속 행동) |
| 성기사 | 전설 | 신성 강타와 주변 치유 |
| 투석병 | 일반 | 곡사: 막혀 있어도 2~3칸 안의 적을 맞힘 |
| 척후병 | 일반 | 세 칸 이동 후 옆의 적을 자동으로 기습 |
| 수도승 | 일반 | 근접 공격을 받고 버티면 반격 |
| 독술사 | 희귀 | 3턴 동안 매 턴 독 피해 |
| 대포병 | 희귀 | 먼 거리 포격 + 주변 폭발 피해 |
| 마검사 | 희귀 | 벨 때마다 체력 회복 |
| 수호기사 | 희귀 | 가호: 아군에게 피해 3을 막는 보호막 |
| 폭탄병 | 희귀 | 쓰러지면 터져서 주변 적에게 3 피해 |
| 골렘 | 영웅 | 돌 피부: 모든 피해 -1, 체력 16 |
| 흡혈귀 | 영웅 | 박쥐 떼로 피해를 주고 그만큼 회복 |
| 환영술사 | 영웅 | 3칸 안의 아무 기물과 자리 바꾸기 |
| 전쟁군주 | 영웅 | 옆의 아군 공격력 +1 |
| 대마법사 | 전설 | 운석: 판 어디든 3×3 범위 3 피해 |
| 불사조 | 전설 | 출전마다 한 번 쓰러져도 환생 |

## 코드 구성

```
js/data/      기물 정의(pieces.js), 웨이브 생성(waves.js)
js/game/      전투 규칙(battle.js: 상태 + 이벤트), 적 AI(ai.js)
js/render/    보드 렌더러와 연출(board-view.js), 스프링/트윈(anim.js), 픽셀 스프라이트(sprites.js)
js/fx/        카오스체스 전용 이펙트(effects.js)
js/ui/        상점, 편성, 전투 화면
lib/pixelfx/  pixelfx 코어 (MIT): 픽셀 이펙트용 Painter, 파티클, 조명
dev/          스프라이트·이펙트 확인용 페이지
```

이펙트는 pixelfx의 기본 샘플 이펙트를 쓰지 않고, 코어 툴킷만으로 새로 만들었어요. `dev/fx.html`에서 시간별 컨택트 시트로 확인할 수 있어요.
