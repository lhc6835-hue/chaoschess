# 카오스체스

기물마다 능력이 다른 체스 응용 턴제 웨이브 게임이에요. 브라우저에서 바로 돌아가고 빌드 과정이 없어요.

## 실행

ES 모듈을 쓰기 때문에 파일을 더블클릭하지 말고 정적 서버로 열어주세요.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

## 게임 구조

- **메인 화면**: 상점, 편성, 출전. 골드와 보유 기물은 브라우저에 저장돼요(영구 성장).
- **상점**: 등급(기본·일반·희귀·영웅·전설)과 성능에 따라 가격이 달라요. 카드마다 이동(청록)·공격(빨강) 패턴 미니맵이 있어요.
- **편성**: 앞줄 8칸, 뒷줄 8칸. 킹은 꼭 넣어야 해요. 기물을 팔면 반값을 돌려받아요.
- **전투**: 내 기물을 고르고 표시된 칸을 누르면 선택지(이동, 공격, 능력)가 나와요. 한 턴에 기물 하나만 움직여요.
  - 근접 기물은 적을 쓰러뜨리면 그 칸으로 전진하고, 원거리 기물은 제자리에서 쏴요.
  - 적을 모두 쓰러뜨리면 다음 웨이브로 넘어가요. 웨이브가 오를수록 적의 수, 등급, 체력, 공격력이 올라가고 5의 배수 웨이브엔 마왕이 나와요.
  - 웨이브 사이엔 상점이 없어요. 쓰러진 기물은 그 출전에서 돌아오지 않아요. 살아남은 기물은 원래 자리로 돌아가고 최대 체력의 20%를 회복해요. 그다음 아래 두 줄 안에서 자리를 바꿀 수 있어요.
  - 킹이 쓰러지면 출전이 끝나요. 번 골드는 그대로 남아요.

## 소리와 화면 전환

- 메인 화면, 전투, 마왕 웨이브마다 배경음악이 바뀌어요(크로스페이드). 웨이브 시작·클리어·게임 오버엔 징글이 나와요.
- 효과음은 기물 위치에 따라 좌우로 패닝되고, 같은 동작도 매번 음높이가 조금씩 달라요.
- 왼쪽 아래 버튼에서 배경음악·효과음 크기를 조절하거나 끌 수 있어요.
- 화면이 바뀔 땐 체스판 칸이 대각선으로 튀어나와 덮었다가 걷혀요. 출전할 땐 나이트가 L자로 뛰어 지나가고, 패배하면 진홍색 칸이 덮여요.

## 특수 능력 기물

| 기물 | 등급 | 능력 |
|---|---|---|
| 창병 | 일반 | 가로세로 두 칸을 꿰뚫어 찌르기 |
| 궁수 | 일반 | 2~4칸 원거리 사격 |
| 방패병 | 일반 | 옆 아군 받는 피해 -1 |
| 화염술사 | 희귀 | 화염구: 3×3 범위 피해 |
| 빙결술사 | 희귀 | 맞은 적은 다음 턴 행동 불가 |
| 사제 | 희귀 | 치유 |
| 암살자 | 희귀 | 체력이 가득 찬 적에게 두 배 피해 |
| 네크로맨서 | 영웅 | 보라색 해골 소환, 근처에서 쓰러진 적을 해골 아군으로 |
| 뇌전술사 | 영웅 | 연쇄 번개 |
| 광전사 | 영웅 | 처치할 때마다 공격력 +1 |
| 드래곤 | 전설 | 한 줄 3칸 화염 숨결 |
| 시간술사 | 전설 | 순간이동, 시간 가속(연속 행동) |
| 성기사 | 전설 | 신성 강타와 주변 치유 |

## 코드 구성

```
js/data/      기물 정의(pieces.js), 웨이브 생성(waves.js)
js/game/      전투 규칙(battle.js: 상태 + 이벤트), 적 AI(ai.js)
js/render/    보드 렌더러와 연출(board-view.js), 스프링/트윈(anim.js), 픽셀 스프라이트(sprites.js)
js/fx/        카오스체스 전용 이펙트(effects.js)
js/ui/        상점, 편성, 전투 화면
lib/pixelfx/  pixelfx 코어 (MIT): 픽셀 이펙트용 Painter, 파티클, 조명
dev/          스프라이트·이펙트 확인용 페이지
```

이펙트는 pixelfx의 기본 샘플 이펙트를 쓰지 않고, 코어 툴킷만으로 새로 만들었어요. `dev/fx.html`에서 시간별 컨택트 시트로 확인할 수 있어요.
